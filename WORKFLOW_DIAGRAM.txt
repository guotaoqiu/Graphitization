================================================================================
                         EXTRACTED PROPERTIES
================================================================================

For each doped structure:
  ✓ Lattice parameters (a, b, c, α, β, γ)
  ✓ Unit cell volume
  ✓ Interlayer spacing (average, min, max)
  ✓ Number of layers
  ✓ Total energy
  ✓ Energy per atom
  ✓ Formation energy (relative to pristine)
  ✓ Composition and doping information

================================================================================
                         ANALYSIS CAPABILITIES
================================================================================

1. Compare interlayer spacing across dopants
2. Identify dopants that expand/contract graphite
3. Rank by formation energy (stability)
4. Separate substitutional vs interstitial effects
5. Correlation analysis (spacing vs. dopant properties)
6. Statistical analysis by element, doping type, etc.
7. Generate publication-quality plots and figures
8. Export to MongoDB-compatible JSON format
9. Upload to database for advanced queries
10. Aggregate and filter data using MongoDB queries
